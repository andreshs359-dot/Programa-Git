# Programa-Git

## Proyecto formativo ACTIVACOOP

Ejercicio práctico de control de versiones aplicado al desarrollo
del sistema web de gestión e inscripción a eventos de ACTIVACOOP.

## Objetivo

Aplicar los comandos básicos de Git para administrar los cambios
del código fuente y sincronizar un repositorio local con GitHub.

## Tecnologías y herramientas

- HTML
- Git
- GitHub
- Visual Studio Code
